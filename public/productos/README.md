# Fotos de productos

Dejá acá las fotos de cada relleno con estos nombres exactos (formato `.jpg`):

- `vacio-mozzarella.jpg`
- `jamon-queso.jpg`
- `mozzarella-tomate-albahaca.jpg`
- `boniato-azul-nueces.jpg`
- `pollo-verduras.jpg`

Recomendaciones:
- Aspect ratio 16:9 (ej: 1280x720 px)
- Comprimidas a < 200 KB cada una (usá tinypng.com o squoosh.app)
- Iluminación cálida, fondo neutro

Si agregás un producto nuevo en `src/lib/productos.ts`, sumá su foto acá con el slug que pongas en el campo `imagen`.
